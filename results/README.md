# Results

Generated outputs. Large/intermediate files are **git-ignored** and are regenerated by
running `01`–`03`; only small, final, curated tables are committed here.

## Layout

```
results/
  intermediate/      # git-ignored: per-step objects, full GSEA/DE dumps, .rds
  figures/           # git-ignored: rendered figures from 04_figures templates
  tables/            # committed: small final/curated summaries used in the paper
```

## What each pipeline produces

- `01_snRNAseq` → Original/DecontX integrated objects; V1/V2/V3 astrocyte objects;
  per-version DE and GSEA tables (353 / 156 / 87 GO-BP terms); 10-group and subgroup
  tables; immune 111→26→4 and conserved-program summaries.
- `02_bulkRNAseq` → DESeq2 DE tables and GSEA tables (911 Aβ42, 308 BKO); culture
  purity check.
- `03_cross_dataset` → GO-ID/NES alignment tables, shared leading-edge tables,
  Aβ42×snRNA and BKO×Aβ42×V3 overlaps, capped log2FC heatmap matrices.

> Curated tables whose final labels were assigned manually (functional-group and
> subgroup naming) are committed to `tables/` with a short note distinguishing
> automatic output from manual curation.
